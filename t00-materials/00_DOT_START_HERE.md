## 6. 不可绕过的验收条件

- Agent 只能持有会话执行凭据；compat 模式禁止退回项目级 Key。
- 精确固定用户、Agent、连接和 Action；空白名单不得映射成全权限，不 fallback 到默认账号或另一后端。
- 多用户同 provider 授权不得相互替换；验证授权完成者的实际 Multica 登录身份，不能只看 URL 或签名 state。
- 本地禁用、第三方撤权、凭据删除分别记录；失败、不支持和未知结果不能报成功。
- 写操作 UNKNOWN 不盲重试；任务排队、撤销、超时和恢复不得复活旧权限。
- 不支持的 API、元工具或 provider 能力明确拒绝；对外兼容声明绑定版本与证据。
